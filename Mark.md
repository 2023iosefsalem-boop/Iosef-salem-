# Creación de cuenta en GitHub y primer commit

## Resumen
- Crearemos una cuenta de GitHub.
- Crearemos un repositorio (un lugar donde se guardan los proyectos).
- Haremos una prueba.

## Pasos para la actividad

1. Entrar a [github.com](https://github.com) y crear una cuenta utilizando el correo institucional.
2. Hacer clic en **NEW**.
3. Escribir `primer-repositorio` y tocar **Create repository**.
4. Activar la opción que dice **Add README**.

A continuación, aparecerá el repositorio vacío.

## Primer commit de prueba

1. Dentro del repositorio, apretar la tecla `.` (punto) — esto abre **GitHub.dev** (un editor de código online).
2. Si aparece un cartel de solicitud de permisos, hacer clic en **Permitir**.
3. Hacer clic en **Continue**.
4. Hacer clic en donde dice **README.md**.
5. Borrar el contenido por defecto y escribir el contenido solicitado.
6. Hacer clic en el icono del control de código fuente (Source Control).
7. Escribir `Primer mensaje de prueba` en el mensaje de cambio y tocar el botón **Confirmar y enviar cambios**.
8. Hacer clic donde dice **>< GitHub** y seleccionar la opción **Ir a repositorio**.

Se abrirá una pestaña nueva con el archivo ya creado y editado.

¡Terminamos la prueba de crear una cuenta de GitHub y realizar la primera edición de un archivo online!
